# Changelog

All notable changes to **Bhavesh Patil Portfolio** will be documented in this file.

## [2.4.0] - 2026-09-30

### Added
- **AI Authentication Protocol Modal (`TermsConsentModal`)**: Viewport-safe AI modal with 1-click agreement, ESC key listener, and zero-data exploitation pledge.
- **Dedicated Legal Pages**: `/terms`, `/privacy`, and `/cookies` with interactive storage inspector.
- **Active JWT Authentication**: Bearer token headers for protected user actions.
- **Smooth Navigation**: Lenis smooth scrolling for hero action button to `#selected-work`.
- **Expanded AI Chat Knowledge Base**: Detailed project architectures, education profile, and offline fuzzy intent matching.

### Changed
- Streamlined metrics section into a symmetrical 3-card layout.
- Modernized AI chat bubble UI with rich markdown rendering and quick suggestion chips.

### Security
- Added GDPR & CCPA compliant cookie preferences banner.
- Implemented rate limiting and input sanitization on all inquiry forms.
